# Farseek Hindi glossary

Language id `hi`: modern standard Hindi in Devanagari. Source of the translations: `outputs/i18n/work-hi/tr/*.json`, built into `game/i18n/hi.js` by `node outputs/i18n/work-hi/build.mjs`.

## Conventions

| Topic | Rule |
| --- | --- |
| Register | The player is addressed with तुम (imperatives in -ओ: दबाओ, चुनो, कूदो). Nyra and Mira take feminine agreement (मैं जाऊँगी, तुम गिरीं). |
| Character voices | Mira speaks to Nyra with तुम, warm and dry. The clerk and the Wardens use stiff officialese with आप and कृपया (लाइन में वापस जाइए), which is the comic register of an Indian government counter. Journal pages are terse first person field notes (हम for the first expedition). |
| Inserted names | `{world}`, `{title}`, `{action}`, `{bay}`, `{glyph}`, `{attack}`, `{craft}` stand after a colon or in a list, never before a postposition, so no oblique ending is needed (`{world}: तैयारी चल रही है…`). |
| Key caps | `{key}`, `{press}`, `{interact}` and similar come before the verb (`{key} दबाओ`, `छोड़ने के लिए {press}`). Purpose clauses go first, the key phrase last. |
| Key names | Keys printed on Indian keyboards stay in Latin letters: Esc, Enter, Tab, Shift, Ctrl, Alt, Backspace, Caps Lock, Num. The unlabeled bar is स्पेस. Gamepad buttons are transliterated (स्टार्ट, व्यू, होम, डी-पैड ऊपर); face and shoulder button letters (A, B, LB) stay Latin. |
| Punctuation | Sentences end with the danda `।`; `?`, `!`, `,`, `:`, `;`, `…` and `·` as in English. Western digits. No punctuation dashes; hyphens join compounds (हिम-बिलाव, दबाव-सील). |
| Spelling | Nukta only on ज़ and फ़ (plus the native ड़, ढ़); क, ख, ग are written without it (आखिरी, खतरा, गलत). The build normalizes this. Chandrabindu where the vowel sign stays under the headline (हाँ, पहुँचो, साँस), anusvara otherwise (में, नहीं). |
| Units and time | Metric. Seconds are written out: `{n} सेकंड`. "X of Y" is `Y में से X`. |
